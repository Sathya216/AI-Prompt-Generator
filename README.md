# 🤖 AI Prompt Generator

A simple and interactive web application that helps users create
ready-to-use AI prompts for different purposes such as coding,
interviews, resumes, and learning.

## ✨ Features

- 🎯 Select a purpose
- 💡 Enter your topic
- 🤖 Generate a useful AI prompt
- 📋 Copy the generated prompt
- 📱 Simple and responsive user interface
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How It Works

1. Select a purpose from the dropdown.
2. Enter your topic.
3. Click the **Generate Prompt** button.
4. Your customized AI prompt will be displayed.
5. Click **Copy Prompt** to copy it.
